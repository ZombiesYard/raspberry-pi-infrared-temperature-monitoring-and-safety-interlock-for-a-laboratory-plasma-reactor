Place a full runnable Tesseract Windows folder here if you want a fully
self-contained lab package.

Required file:
  tesseract.exe

Recommended subfolder:
  tessdata\\eng.traineddata

Important:
  Do not run the Windows Tesseract installer directly into the artifacts
  release folder. Install Tesseract to a normal Windows location such as
  C:\Program Files\Tesseract-OCR first, or copy an already installed folder
  here afterward.
