Offline package contents
========================

1. Install the CP210x driver from:
   offline-deps\cp210x-driver\silabser.inf

2. For Tesseract, use one of these methods:
   - Copy a full runnable Tesseract folder to:
     offline-deps\tesseract\
     so that this file exists:
     offline-deps\tesseract\tesseract.exe
   - Or install Tesseract to a normal Windows folder such as:
     C:\Program Files\Tesseract-OCR\tesseract.exe

   Do not run the Tesseract installer directly into the artifacts release
   folder. Install to a normal Windows folder first, or copy an already
   installed portable folder afterward.

3. Run:
   ReactorSoftInterlock.Wpf.exe

4. For the current relay-interlock-test branch:
   - Relay COM Port default: COM3
   - Relay command defaults:
     AT+CH1=0 / AT+CH2=0 / AT+CH3=0 / AT+CH4=0
     AT+CH1=1 / AT+CH2=1 / AT+CH3=1 / AT+CH4=1
   - Recommended G2000 relay mapping:
     CH1 -> I1-I2
     CH2 -> I5-I6
     CH3 -> I3-I4
     CH4 -> I7-I8
   - AMC2100 defaults:
     COM4 / 19200 / slave 1 / digital mode forced
   - The top dashboard shows live AMC2100 actual flow when AMC2100 is enabled and Dry Run is off.
